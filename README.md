# FF Codes Hub

A mobile-first Free Fire redeem-code website starter.

## Files
- `index.html` — public website
- `style.css` — responsive design
- `app.js` — code list + copy buttons
- `admin.html` — admin-panel UI starter

## Before publishing
1. Replace the example codes in `app.js` with verified codes.
2. Add a real backend/database and authentication for the admin panel.
3. Add your privacy policy, terms, contact/about pages and other pages needed for AdSense review.
4. Keep ads separate from access to codes. Do not require ad clicks or ad views to reveal a code.
5. Use only official redemption links and clearly state that the site is not affiliated with Garena.

## AdSense
Place normal ad units in suitable content areas after your site is ready. Never incentivize users to click ads, and never label ads as buttons such as "Click to unlock code".
